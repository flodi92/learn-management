## Renamings

I want you to change the wording in the whole app in the following way:

Check every type name, variable name and file name in the whole src folder and adopt everything. Do not adopt anything in folder regExp2

Check also if the naming occures as part of another name and adopt that, too.

Those are the renamings:
LearnSubject > TaskDescription
Subject as generic type > TD
Subject in another name > TaskDescription
Task => TaskDescription

At the end verify that the namings Subject or Task do not appear neither in a variable name, a type name nor in a file name.
